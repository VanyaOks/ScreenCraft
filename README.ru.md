# ScreenCraft — аннотации скриншотов для DSH

> English version: [README.md](README.md)

**ScreenCraft** — плагин для DSH (DeepSeek Harness), добавляющий редактор
аннотаций скриншотов. В панель инструментов композера добавляется кнопка
**«Аннотировать скриншот»**. Открывается полноэкранный редактор: скриншот
вставляется через `Ctrl+V`, перетаскивается или выбирается файлом, после чего
на нём можно ставить:

- пронумерованные точки, прямоугольники, стрелки и линейки — у каждой метки свой цвет и комментарий;
- цвет = назначение: в палитре и меню правой кнопки выбирается смысл метки — ошибка (красный), поправить (жёлтый), так и надо (зелёный), вопрос (синий), важно (оранжевый), идея (фиолетовый), пояснение (голубой), связь (розовый); в легенде цвет подписан назначением;
- объединение нескольких меток в одну группу под общий номер и общий комментарий (например, три стрелки с одним смыслом): отметьте метки флажками в списке и нажмите «Объединить»; «Разъединить» возвращает их обратно;
- номера всегда идут подряд: после удаления метки оставшиеся перенумеровываются без пропусков;
- выделение на холсте: рамкой или Shift+кликом выбираются несколько меток, их можно двигать вместе, удалять, объединять и дублировать (Ctrl+D); номера бейджей автоматически расходятся, чтобы не перекрываться;
- стили линий: обычная/пунктирная, один/два наконечника, тонкая/обычная/толстая, прямая/дуга — для новых и для выбранных меток (правая кнопка мыши);
- инструмент «Скрыть»: выделенная область пикселизуется, чтобы убрать из скриншота пароли и персональные данные;
- аннотации сохраняются в браузере по хэшу картинки и восстанавливаются, если вставить тот же скриншот снова;
- горячие клавиши: M/P/R/A/L/X — инструменты, Delete — удалить выбранное, Ctrl+Z / Ctrl+Shift+Z, Ctrl+D — дублировать, Esc — снять выбор/закрыть;
- зум колесом мыши к курсору, панорамирование пробелом или средней кнопкой мыши, Shift+колесо — горизонтальная прокрутка;
- экспорт в PNG, JPEG или WebP (выбор внизу); режим «Только текст» отправляет только координаты и комментарии без картинки;
- пакетная разметка: «В очередь» добавляет текущий скриншот в очередь, можно вставить следующий и отправить все одним сообщением;
- линейка для обозначения линии выравнивания: инструмент «Линейка» рисует линию с засечками на концах; если при рисовании удерживать **Shift**, наклон привязывается к шагу 10° (как в Photoshop);
- правая кнопка мыши по картинке открывает меню: тип метки и цвет; по существующей метке меняет её форму и цвет;
- инструмент перемещения для правки и удаления готовых меток;
- отмена/повтор, масштаб, кнопка «Вписать» и список меток с отдельным полем комментария;
- адаптивная раскладка: у горизонтального скриншота панель меток уходит под изображение и изображение получает всю ширину, у вертикального — остаётся справа; панель меток можно свернуть;
- при открытии скриншот автоматически вписывается целиком, без прокрутки: горизонтальный — по обеим сторонам (панель меток снизу при этом свёрнута), вертикальный — по ширине;
- пустые однотонные поля вокруг содержимого (рабочий стол, пустой холст) обрезаются автоматически, а кнопка «Вернуть» возвращает исходный кадр; для ручной обрезки есть инструмент «Обрезать».

## Установка

Репозиторий — это готовый бандл, сборка не нужна. Установка в профиль DSH:

1. Откройте веб-интерфейс DSH → **Настройки → Плагины**.
2. Установите бандл по URL `https://github.com/VanyaOks/Screenshot`.
   В сеансе DSH можно также попросить агента установить этот URL.
3. Обновите страницу. Кнопка аннотации появится в панели инструментов композера.

После установки плагин работает во всех сеансах этого профиля.

По кнопке **«Вставить в чат»** браузер экспортирует PNG с уменьшенным размером
для экономии токенов, Host-половина сохраняет его в `<рабочая папка>/.dsh/annotations/`,
а в композер вставляется компактная расшифровка меток вместе с относительным
путём к файлу, например:

```
Скриншот с метками: .dsh/annotations/annotation-20261114-125501-ab12.png (1024×576) — прочитай изображение через read_image.
Метки (координаты — % от ширины×высоты):
#1 красный прямоугольник 12–40% × 5–18%: кнопка слишком близко к краю
#2 синяя точка 55%,30%: здесь неверная подпись
```

Проверьте вставленный текст и нажмите «Отправить». Агент получает картинку с
метками, точные координаты и текст комментариев, а сам файл читает инструментом
`read_image`.

## Почему файл, а не вложение

Чтобы добавить картинку как вложение к черновику, нужны приватные API
композера, которых нет в публичной поверхности плагинов. Связка «Host-маршрут +
файл в рабочей папке» — стабильный путь: плагин не подменяет чужие слоты и не
читает чужой DOM, а агент читает изображение своими файловыми инструментами.
Если сохранить файл не удалось, плагин скачивает PNG и копирует расшифровку в
буфер — работа не пропадает.

## Экономия токенов

Длину длинной стороны экспорта можно выбрать: 768 px (по умолчанию), 1024 px,
1536 px или оригинальный размер. Редактор показывает примерную стоимость
картинки в токенах для текущего выбора. В чат уходит одно изображение и
компактная расшифровка меток.

## Куда сохраняются файлы

В `<рабочая папка>/.dsh/annotations/` со сгенерированными именами. Старые файлы
удаляются: остаются последние 200 и не старше недели. Скриншоты могут содержать
секреты: никуда, кроме собственных инструментов агента, они не отправляются, а
маршрут принимает только same-origin POST-запросы с локальной страницы.

## Область применения

- Аннотирование **до отправки**: вставьте или перетащите скриншот в редактор.
- Уже отправленный скриншот можно перетащить из чата обратно в композер, а затем
  открыть в редакторе.
- Соответствие цветов — договорённость, а не жёсткое правило: красный — сломано,
  жёлтый — поправить, зелёный — так и надо, синий — вопрос.
